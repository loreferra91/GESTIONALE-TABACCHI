Collegamento al gestionale

Riconosce esclusivamente il servizio FastAPI già avviato sul tuo computer, all'indirizzo 127.0.0.1:18085. Non contatta Render né MongoDB Atlas.

Premi «Verifica servizio» per iniziare.

L'apertura usa una seconda finestra nativa, senza concedere comandi privilegiati alla pagina web.

Perché non si avvia automaticamente?

Il backend Python confezionato è previsto solo nella variante Runtime Lab. Richiede un MongoDB locale autenticato già avviato e credenziali nel portachiavi di sistema; nessuna variante avvia automaticamente MongoDB. Gli installer non sono ancora certificati per uso operativo.

Per un test con dati sintetici, consulta docs/DESKTOP_GATE5_PREVIEW.md nel repository GitHub e avvia separatamente il runtime locale sperimentale.
